<h1>Sobre o Finmo</h1>
<p>O Finmo é uma calculadora financeira online que combina simplicidade, design intuitivo e precisão nos cálculos para ajudar você a tomar decisões financeiras com mais segurança.</p>

<h2>Funcionalidades</h2>
<ul>
  <li>Cálculo de juros simples e compostos.</li>
  <li>Simulação de investimentos em CDB (com desconto automático de IR).</li>
  <li>Simulação de investimentos em LCI e LCA (isentos de IR).</li>
</ul>
